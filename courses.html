1. Network Fundamentals — 20%

Key Topics Include:

  • Role and function of routers, L2/L3 switches, firewalls, access points, controllers, servers, endpoints, PoE
  • Network topologies: two‑tier, three‑tier, spine‑leaf, WAN, SOHO, on‑premises/cloud
  • Cabling types: single‑mode fiber, multimode fiber, copper; Ethernet shared media vs point‑to‑point
  • Interface/cable issues: collisions, errors, duplex/speed mismatch
  • TCP vs UDP
  • IPv4 addressing, subnetting, private addressing
  • IPv6 addressing, prefixes, address types (unicast, anycast, multicast, EUI‑64)
  • Wireless principles: channels, SSID, RF, encryption
  • Virtualization fundamentals: server virtualization, containers, VRFs
  • Switching concepts: MAC learning, aging, frame switching, flooding, MAC table

2. Network Access — 20%

  • VLANs (normal range), access/voice ports, default VLAN, inter‑VLAN connectivity
  • Interswitch connectivity: trunk ports, 802.1Q, native VLAN
  • Layer 2 discovery protocols: CDP, LLDP
  • EtherChannel (LACP)
  • Rapid PVST+ STP: root bridge, port roles/states, PortFast, root guard, loop guard, BPDU guard/filter
  • Cisco wireless architecture, AP modes, WLC connections, WLAN components

3. IP Connectivity — 25%

  • Routing table interpretation
  • Router forwarding decisions
  • Static routing (IPv4/IPv6)
  • OSPFv2 single‑area: neighbor adjacency, point‑to‑point vs broadcast, router ID
  • First‑hop redundancy (HSRP)

4. IP Services — 10%

  • NAT (static, PAT)
  • NTP
  • DHCP, DNS
  • SNMP, syslog
  • QoS (per‑hop behavior)
  • SSH
  • TFTP/FTP functions

5. Security Fundamentals — 15%

  • Threats, vulnerabilities, exploits
  • Security program components
  • Device access control, password policies
  • VPNs (remote access, site‑to‑site)
  • ACLs
  • Layer‑2 security: port security, DHCP snooping, dynamic ARP inspection
  • Wireless security: WPA2/WPA3

6. Automation & Programmability — 10%

  • Traditional vs controller‑based networking
  • REST APIs
  • JSON
  • Automation tools (Ansible, Terraform) at recognition level
